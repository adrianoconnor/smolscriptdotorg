Roadmap

Coming soon

We're still in the early phases of this project so things change fast. This is our current roadmap for the next version:

  • More standard library classes and functions (Console, Date, JSON, etc)
  • Support for passing JSON or arbitrary objects to/from the host
  • Interactive mode when execution paused (and also a REPL)

Currently the .net and JS/TS versions are roughly in-sync. Sometimes one version gets a little bit ahead of the other.

Probably not coming soon

The following features are not on our immediate roadmap:

  • Async/Await
  • Import/require modules
  • Better performance

Please remember this is a hobby project. We prioritise simplicity and compactness over performance and features. I might explore adding some sort of support for modules and async/await one day, but no promises.
